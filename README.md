## 🎯 What You Will Build

By the end of this course, you will have built:

- 🗂️ **PDF Chatbot** — Chat with any document using RAG
- 🔍 **Web Search Agent** — An agent that autonomously browses and summarizes
- 💻 **Coding Assistant** — AI that reads, writes, and debugs code
- 📊 **Research Assistant** — Multi-agent system for deep research
- 🤖 **Personal AI Assistant** — Your own production-ready AI assistant

---

## 🧠 Who Is This For?

This course is designed for **software developers, backend engineers, and system programmers** who want to understand and build real AI systems — not just use them.

**You should know:**
- Basic Python programming
- How APIs work (REST/JSON)
- Command line basics

**You do NOT need:**
- Machine learning background
- Math / statistics knowledge
- Prior AI experience
