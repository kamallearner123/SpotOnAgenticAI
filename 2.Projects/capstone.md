## Quick Reference

**Presentation Date:** June 15, 2026, 3:00 PM  
**Duration:** 8–10 minutes per person  
**Format:** Live code demo (not slides)

## Must Include

- [ ] Working AI application (no slideware demos)
- [ ] At least 1 LLM + 2 of: Tools, RAG, Memory, Multi-agent
- [ ] GitHub repo with README
- [ ] Live demo during presentation
